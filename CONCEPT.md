# AutoDJ Mixer — концепт

> Простыми словами: что это, зачем и как работает

## Идея

**AutoDJ Mixer** — это программа, которая делает то же, что и живой диджей на пульте: берёт несколько музыкальных треков и плавно сводит их один в другой, создавая непрерывный микс.

Но вместо рук диджея всем управляет код.

## Зачем это нужно?

Диджеи тратят часы на:
- поиск совместимых треков (одинаковый BPM, тональность, жанр)
- выстраивание их в правильном порядке (энергетическая дуга: разогрев → пик → затихание)
- сведение переходов (чтобы трек А плавно стал треком Б без "швов")

AutoDJ Mixer делает всё это автоматически. Человек только задаёт жанр, tempo и тональность — остальное делает программа.

## Как это работает (общая схема)

```
[Поиск треков] → [Загрузка] → [Анализ] → [Сведение] → [Проверка] → [Отчёт]
       ↓              ↓            ↓           ↓            ↓           ↓
   Beatport       YouTube      Madmom     smart_mixer   mix_analyzer  DJ AGENT
   Bandcamp       yt-dlp       A1F        LR4 crossover feedback      Telegram
   Discogs                     librosa    EQ sweep                    catbox
```

## Этапы подробно

### 1. Поиск треков (Curation)

Программа сама находит подходящие треки. Это как если бы диджей листал Beatport, Bandcamp и Discogs в поисках материала.

**Инструменты:**
- `playwright_scraper.py` — виртуальный браузер, который заходит на Beatport и Bandcamp, собирает информацию о треках. Обходит антибот-защиту через Playwright + stealth.
- `curate_tracks.py` — «мозг» поиска: запускает все источники, собирает пул треков, отфильтровывает неподходящие по BPM и тональности.

**Откуда берём треки:**
- **Beatport** — DJ-чарты, 42 подборки × 20 треков = ~125 треков с BPM и тональностью
- **Discogs** — каталог по жанру, ~37 треков
- **Bandcamp** — андеграунд, ~40 альбомов (через Cloudflare Warp)

**Что на выходе:** JSON-файл с кандидатами и список YouTube-ссылок для скачивания.

### 2. Загрузка (Download)

Скачиваем найденные треки с YouTube в WAV-формате (без потерь).

**Инструменты:**
- `yt_download.py` — загрузчик на базе yt-dlp
- Cloudflare Warp — прокси, чтобы YouTube не блокировал

**Важно:** скачиваем только последовательно, по одному треку. Параллельная загрузка = бан от YouTube.

### 3. Анализ (Analysis)

Каждый скачанный трек нужно «понять»: где у него биты, какой темп, тональность, где куплеты и припевы.

**Инструменты:**
- **Madmom** — нейросеть, которая находит удары (downbeats) в треке. Строит ритмическую сетку.
- **All-in-One-Fix (A1F)** — нейросеть, которая разделяет трек на вокал/бас/барабаны/остальное (Demucs) и определяет структуру: интро → куплет → припев → бридж → аутро.
- **Librosa** — определяет тональность и BPM.
- `enrich_metadata.py` — обогащает трек метаданными: исполнитель, название, год, страна, ссылка на YouTube.

**Что на выходе:** для каждого трека — JSON с метаданными, ритмическая сетка (downbeats в секундах), структурные сегменты.

### 4. Сведение (Mixing)

Самый сложный этап. Программа берёт два трека и решает, как их соединить.

**Инструмент:** `smart_mixer.py` (~2300 строк кода).

**Что происходит:**
1. Выбираются точки входа (где начинать новый трек) и выхода (где закончить старый).
2. Рассчитывается зона перехода — от 22 до 60 секунд, в зависимости от энергетики треков.
3. В зоне перехода работает цепочка DSP-эффектов:
   - **LR4 crossover** — разделение на низкие и высокие частоты
   - **EQ sweep** — фильтр низких частот, чтобы басы не конфликтовали
   - **Bar-by-bar warp** — подстройка темпа треков друг под друга (pyrubberband)
   - **Micro-shift** — сдвиг ритмической сетки для точного совпадения downbeat'ов
   - **RMS stabilizer** — выравнивание громкости
   - **LUFS gating** — контроль уровня, чтобы не было резких скачков
4. Треки склеиваются в один файл.

**Правила переходов (жёсткие требования пользователя):**
- Ни один переход короче 22 секунд
- 70% переходов — длиннее 28 секунд
- Некоторые переходы — 40-60 секунд (для атмосферных смен)

### 5. Проверка (Validation)

После сведения программа проверяет качество.

**Инструменты:**
- `mix_analyzer.py` — ищет артефакты:
  - **band_cancellation** — «бочка» в басах (фазовая отмена)
  - **onset_stability** — эхо на ударных (двойное срабатывание транзиентов)
  - **P-score** — общая оценка качества сведения
- `mix_validator.py` — итоговая валидация

**Если есть проблемы:** программа предлагает укоротить переходы или сменить DSP-режим.

### 6. Публикация (Delivery)

Готовый микс отправляется слушателю.

**Инструменты:**
- **Catbox** — файлообменник (бесплатный, 1GB лимит)
- **Telegram** — канал для доставки

**Формат:** MP3, если больше 50MB — пережимаем в 96kbps.

**Что в отчёте (DJ AGENT формат):**
- Сообщение 1: трек-лист с таймкодами, ссылками на YouTube, странами, техникой каждого перехода
- Сообщение 2: технический стэк, диггерский лог, sound prompt (для Suno/Udio)

## Кто использует?

Один человек — диджей Стас. Он даёт команду в Telegram:
- «сделай микс techno 140 BPM 8A»
- «найди треки для French Touch 122 BPM»
- «проанализируй последний микс»

Программа работает на VPS (Contabo, 4 vCPU, 8GB RAM, без GPU).

## Агенты-помощники

У программы два ИИ-агента, которые работают по очереди:
- **Hermes** — делает анализ, сведение, поиск треков
- **ClaudeClaw (cclaw)** — делает варпинг, AI-переходы, пайплайн

Оба агента работают в одной папке `/opt/autodj-mixer/` и используют общий SKILL.md как инструкцию.

## Что не работает (и почему)

- **Resident Advisor** — заблокирован системой DataDome (антибот). Нужен платный резидентский прокси.
- **1001tracklists** — заблокирован Cloudflare. Нужен платный резидентский прокси.
- **Tunebat** — ограничивает запросы после 5 штук (429 Too Many Requests).

Без покупки прокси пул ~204 треков — этого хватает для любого микса.
