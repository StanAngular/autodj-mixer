Референсы стиля: **Anyma, ARTBAT, Mind Against** — melodic techno с атмосферой.

## 3. v2 — Правильные решения

### 3.1 Темп и ритм

```python
bpm = 125          # стандарт melodic techno (Anyma = 126-130)
swing = 0.0        # прямой 4/4 без свинга — машинная точность, характерно для техно
drum_pattern = "four_on_floor"  # кик на каждую долю — это и есть техно
drum_bank = "RolandTR909"       # реальные сэмплы TR-909, не GM MIDI
```

**Аранжировка барабанов (P82):**
```
intro(23b) → build(15b) → drop(46b) → breakdown(18b) → build(11b) → drop(51b) → outro(23b)
786 → 694 ударов (прореживание в intro/breakdown)
```
- В **intro**: только кик + редкий хэт, снейра нет
- В **breakdown**: кик уходит полностью (0 ударов) — напряжение перед дропом
- В **drop**: полная плотность + ghost-снейры (тихие, между долями — «дыхание» грува)
- Перед каждой сменой секции: **филл по томам** (tom_high → tom_mid → tom_low → snare crescendo)

### 3.2 Гармония

**Тональность:** Am (A-доля, 440 Hz основа)
**Лад:** Dorian — натуральный минор с повышенной 6-й ступенью (F#)
```
Ноты дорийского Am: A - B - C - D - E - F# - G
```
Dorian звучит одновременно тёмно и надеждой — именно это даёт эмоциональность Anyma/ARTBAT.

**Прогрессия:** `dark_techno` = **i → VI → III → VII**
```
В Am dorian:
  i   = Am  (A-C-E)           ← опорный аккорд, тёмный
  VI  = F   (F-A-C)           ← светлый момент, "надежда"
  III = C   (C-E-G)           ← мажорный цвет внутри минора
  VII = G   (G-B-D)           ← неустойчивость, толкает обратно к Am
```
Этот цикл (Am → F → C → G) — основа Anyma "Eternity", Mind Against, многих ARTBAT треков.

### 3.3 Инструменты и звуки

| Роль | Инструмент | GM/FluidSynth Patch | Звучание |
|------|-----------|---------------------|----------|
| `pad` | `synth_pad_warm` | GM #90 (Warm Pad) | Широкий тёплый синт-пад, долгий attack |
| `lead` | `synth_lead_sawtooth` | GM #81 (Sawtooth) | Пилообразный лид — резкий, «кислотный», Anyma-style |
| `arp` | `synth_lead_square` | GM #80 (Square) | Квадратная волна для арпеджио — «холодный» текстурный слой |
| `bass` | `synth_bass_1` | GM #38 (Synth Bass 1) | Электронный бас, жёсткий attack |
| `accent` | `tubular_bells` | GM #14 | Редкие акценты, металлический призвук |
| `counter` | `electric_piano` | GM #4 (Rhodes) | Контрапункт-мелодия, тёплый тон |
| drums | `RolandTR909` | Реальные WAV-сэмплы | TR-909: кик (глубокий punch), snare (хлопающий), hh (металлические) |

### 3.4 Мелодическая логика

**melodic_style = "staccato"** — ритм-шаблоны техно:
```python
"staccato": [
    [1.0, 0.5, 0.5, 1.0, 1.0],
    [0.5, 0.5, 1.0, 1.0, 0.5, 0.5],
    [1.5, 0.5, 0.5, 0.5, 1.0],
    ...
]
```
Ноты короткие, между ними паузы → характерный «пульс» техно-лида.

**lead_density = 0.45** — лид играет 45% от возможных нот (не каждую долю, есть «воздух»)
**arp_density = 0.65** — арпеджио плотнее, создаёт движение

### 3.5 Секционные огибающие (P83)

Мелодические слои тоже живут по секциям (не просто фейд на весь трек):

| Секция | pad | lead | arp | bass | counter |
|--------|-----|------|-----|------|---------|
| intro | 0.9 | **0.0** | 0.3 | 0.5 | **0.0** |
| build | 0.9 | 0.5 | 0.8 | 0.9 | 0.4 |
| drop | 0.8 | **1.0** | 1.0 | 1.0 | 0.9 |
| breakdown | **1.0** | 0.8 | 0.4 | **0.3** | 0.6 |
| outro | 0.9 | 0.3 | 0.4 | 0.6 | 0.2 |

→ В **intro** лид молчит, слушатель слышит только грув и пад
→ В **breakdown** пад выходит на первый план, бас проваливается
→ В **drop** всё вместе на полную

### 3.6 Микс-шина (P78/Q1)

Слои не складываются вслепую — каждый слой имеет частотную роль:
```
bass + kick  → низ (sub), остальные слои HPF от 80-100 Hz
mid          → лид/арп (300-3000 Hz)
pad          → mid-high (500-8000 Hz, широкий стерео)
```
Сайдчейн-пампинг: `-4.5 dB` от кика на pad/arp → характерное техно «дыхание»

**Reverb:**
- `fx_lead = (0.72, 0.28, 0.55)` — средний reverb с дэмпом (лид не «плавает»)
- `fx_pad = (0.88, 0.38, 0.40)` — большой hall, атмосфера
- `fx_drums = (0.15, 0.06, 0.82)` — почти сухой (техно = чёткие удары)

## 4. Итог — как это звучит

```
6:00 / 125 BPM / Am dorian / staccato / TR-909

Структура:
  0:00-1:28  INTRO  — только кик + пад, лида нет, хэт редкий
  1:28-2:26  BUILD  — лид появляется на 50%, арп нарастает, хэты дробятся
  2:26-5:07  DROP   — всё вместе, ghost-снейры, пулсирующий бас
  (breakdown внутри) — кик уходит, только пад и лид
  5:07-6:00  OUTRO  — разрежение, всё затихает
```

---

## 5. Что ещё не хватает (для следующих патчей)

1. **Мелодическая изощрённость** — сейчас мотивы генерируются ритм-шаблонами, нет реальной развивающейся мелодии (темы, антецедент-консеквент). Нужен **мелодический генератор с памятью фразы**.
2. **Acid line** — TB-303 паттерн для техно. Сейчас нет `accent_type=acid`.
3. **Текстуры** — rising noise risers перед дропом, глубокий sub drone.
4. **Модуляция фильтра** — lead должен открываться перед дропом (cutoff automation).
5. **Реальные VST** — Surge XT уже установлен, но render_track.py ещё не использует его для лида/арпа (только drum backend).
