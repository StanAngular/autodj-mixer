# autodj.compose: глубина, взаимодействие, поиск звука (P130–P133)

Аудит 2026-11-12. Жалоба Стаса: «примитивно, не качает, далеко до студийного; електронна музика — це пошук нового звуку;
не хватает глибини у всіх елементах та взаємодії елементів». Причины оказались в устройстве движка, а не в отдельных треках.

## Что было не так (по коду на `7781779`)

| Что слышит Стас | Причина в движке |
|---|---|
| Каждый элемент плоский | Тональный слой = одна запись, растянутая по высоте (`sfz.oneshot`): все ноты — одна и та же волна, громче/тише. «Движение» = переход между приглушёнными копиями всего слоя. Внутри ноты и от ноты к ноте не меняется ничего. |
| Элементы не взаимодействуют | `Track.add` сразу суммирует слой в общий стерео-буфер. «Сайдчейн» — часы (провал на каждую долю, играет бочка или нет). У каждого слоя своя реверберация. Ни один слой не может отреагировать на другой. |
| Нет поиска нового звука | `operators.TECHNIQUES` — список из 15 готовых приёмов; `soundq`/`timbre_guard` только отсеивают плохое. Ничто не создаёт звук, которого раньше не было, и не измеряет, нов ли он. |
| Не студийно | Пре-мастер прогонял через `tanh` весь сигнал (бас и пэды искажаются каждой бочкой), «тёплая» цепочка режет верх на 3–5 дБ. |
| Всё проходит проверки, а трек плоский | Все ворота ищут дефекты. Ни одна метрика не спрашивает: движется ли слой, реагирует ли кто-то на кого-то, есть ли планы глубины. |
| Не воспроизводимо | Партитуры треков (`workspace/music/*.py`, `vibe.py`, `techsaw.py`) и рабочая инструкция агента лежат вне репозитория; `GENERATION.md` в репозитории описывает старый движок. |

## Что добавлено (всё по желанию, старые партитуры звучат как раньше)

### 1. Микс-граф — `bus.py`, аргументы `Track.add` (P130)

```python
trk.bus("drums", fx=[glue()], parallel=(smash(), .15))          # группа: общий компрессор + параллельная компрессия
trk.add("kick", kick, 1.0, bus="drums")
trk.add("bass", bass, duck=-7, key="kick")                       # провал по РЕАЛЬНОЙ бочке (её паузы и сбивки слышны в басе)
trk.add("pad", pad, duck=-4, key=["hook", "stab"], band=(400, 3500), depth=.8, send={"hall": .35})
#        ^ пэд уступает хуку только в полосе хука; depth = расстояние (меньше верха, больше комнаты)
trk.add("hook", hook, send={"echo": .22, "room": .12})           # общие пространства: одна комната / холл / эхо на трек
opening = trk.follow("hats", release_ms=900)                     # кривая 0..1 «что играет слой» — для любого параметра другого слоя
```

- `key=` — имя слоя (добавленного раньше), список имён или буфер (призрачная бочка: `key=kick_buffer`).
- Возврат пространства отступает, пока звучат его источники, и раскрывается в паузах (`back_db`).
- Шины вливаются в микс при `finish()` или при первом чтении `trk.mix`. Эффекты на весь микс вызывай после добавления всех слоёв шины.
- Мастер: `META["master"] = "studio"` — без тональной кривой, цель в LUFS, пре-мастер срезает только пики (`premaster="clip"`).

### 2. Живой синтезатор — `synth.py` (P131)

```python
from autodj.compose.synth import Synth, patch
p = patch(osc=[dict(wave="saw", unison=3, detune=9, spread=.15), dict(wave="sine", level=.35)],
          filt=dict(cutoff=190, res=.32, env=3.2, vel=1.6, key=.2, drive=5), amp=dict(a=.002, d=.22, s=.35, r=.07),
          fenv=dict(a=.001, d=.13, s=0, r=.08),
          mods=[dict(src="lfo", dst="cutoff", amt=.7, rate="4b"),      # движение по фразе
                dict(src="rand", dst="cutoff", amt=.25),               # нет двух одинаковых нот
                dict(src="ctl:energy", dst="cutoff", amt=1.0)])        # звук следует за энергией трека / за другим слоем
x = Synth(p, bpm=trk.bpm, seed=seed).render(events, total_s, ctl={"energy": curve})
```

Волны: `saw pulse tri sine noise fm wt`. `wt` — волновая таблица из ЛЮБОЙ записи (`wavetable_from_audio`) или сгенерированная
(`procedural_table`). Источники модуляции: `env amp_env vel rand lfo lfo_note pos time ctl:ИМЯ`. Цели: `cutoff pitch amp res pan pw index pos detune`.

### 3. Лаборатория звука — `soundlab.py` (P132)

```bash
python -m autodj.compose.soundlab search bass --n 48 --keep 6 --out /tmp/lab     # слепая лента A..F + ключ, кандидаты в архив
python -m autodj.compose.soundlab vote bass-20261112-3fa9c1 1 "тёплый, качает"   # 1 / 0 / -1
python -m autodj.compose.soundlab list bass
```
```python
syn = soundlab.Archive().synth("bass-20261112-3fa9c1", bpm=trk.bpm, seed=seed, track=META["title"])   # звук закреплён за треком
```

Поиск: случайные патчи + мутации понравившихся → отказ немым, нестроящим, вне регистра роли, статичным и близким к отклонённым →
оценка по НОВИЗНЕ (расстояние до всего, что уже в архиве) → лучшие из разных областей, непохожие друг на друга.
Архив: `shared/soundlab.json` (`AUTODJ_SOUNDLAB`). Чужие звуки (сэмплы, отклонённые тембры) заносятся `Archive.add_audio`.
Свои записи как материал таблиц: `--source путь.wav ...`.

### 4. Уши для глубины — `depth.py` (P133)

В каждой сводке рендера теперь есть `depth` и `depth_notes` — где трек плоский, словами:
слой-петля без изменений, слой закрыт другим, никто ни на кого не реагирует, duck по часам, все на одном расстоянии,
нет общего пространства, два слоя бьют в одни доли, фактура не меняется N тактов.
Оценки 0..1: `motion`, `interaction`, `space`. Ворота по желанию: `META["gates"] = {"depth_static_max": 0, "depth_links_min": 3, "depth_planes_min": 3, "depth_masked_max": .6}`.

## Порядок работы над треком

1. **Звук сначала.** Для каждой тональной роли — `soundlab search`, лента Стасу, его голоса в архив. В трек идут звуки, которые он выбрал.
2. **Партитура по образцу** `docs/examples/living_demo.py`: шина ударных, duck по ключу, общие пространства, три плана глубины, модуляции от других слоёв.
3. **Рендер** → читать `depth_notes` наравне с `problems` и исправлять до отправки.
4. **Партитуру — в git** (`scores/<трек>.py`), вместе с номером звука из архива. Трек, которого нет в репозитории, нельзя ни проверить, ни повторить.

## Проверка на слух (делает Стас, не агент)

Одни и те же ноты двумя способами:
```bash
python -m autodj.compose run docs/examples/living_demo.py --name living
AUTODJ_DEMO_FLAT=1 python -m autodj.compose run docs/examples/living_demo.py --name flat
```
Вопросы: стало ли глубже; слышно ли, что бас и пэд дышат с бочкой; не мешает ли движение фильтров; какой план лишний.
Ответы — основание для следующих правок, а не цифры `depth.score`.

## Чего это не решает

- Композицию: мелодию, гармонию, форму по-прежнему пишет агент; инструменты выше только дают им звучать.
- Вкус: новизна измеряется, красота — нет. Решает слух Стаса.
- Ударные: синтезированный набор в образце — заглушка; в треках нужен настоящий кит.
