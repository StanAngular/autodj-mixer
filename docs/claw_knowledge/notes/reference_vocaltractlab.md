Стас 2026-11-15 (скриншот reel: «synthetic vocals simulating airways and the human mouth») попросил установить и сделать тесты + вставить в подходящий трек. Это сознательное исключение из правил «только сэмплы» и «никакого псевдо-пения»: допускается ТОЛЬКО как вокальный пэд (гласные, без слов, без слогов, без нарезок), тихо и глубоко в реверберации; остальные запреты действуют.
- Установка: `pip install --user --break-system-packages vocaltractlab` (0.5.8, CPU, speaker JD3). Код: `workspace/music/vtl/voice.py` (`sung(f0, vowels, dur, vib..., breath)`, один тон ~17 с рендера на 8 с звука, нужен `motor_to_audio([MotorSeries])` в списке, частота кадров 441 Гц, 19 параметров тракта + 11 глоттальных: F0, PR давление, ... AS дыхание).
- Подход: рендерить банк тонов один раз (`gen_tones.py`, 4 аккорда x 3 голоса x 2 копии ансамбля, Pool(5) spawn, ~3 мин) и расставлять как семплы, не синтезировать на лету.
- Слух (Gemini, гипотеза): гласные узнаются, «роботизированный вокодер/жужжание», как пэд под электронику годится, громче -37 dB в миксе плохо: слышна пластмассовость. F0 по замеру точный.
- Не пробовано: слоги/согласные (phoneme_to_audio), флейта/духовые физмодели (STK/Faust не установлены).
- 2026-11-15 ПОЮЩИЙ вариант: `workspace/music/vtl/sing.py` (`sing([(слог, midi, длительность)])`: слог = согласные + гласная + согласные, формы JD3 `ll-dental-fricative(a)`, `tt-alveolar-lateral(a)`, ... + глоттальные `voiced-fricative/voiceless-plosive`; голос мужской немецкий JD3, пел на октаву ниже мелодии; параметр `CS=2.0` растягивает согласные: при 1.0 слова не читались). `gen_lines.py` кэширует 4 строки в `vtl/lines/l0..l3.wav` (рендер ~10 с на строку). Трек: `elochka_garage/score.py`.
- Проверка разборчивости: faster-whisper small ru (объективно) + Gemini. Результат: «В лесу ... ёлочка/росла/стройная» узнаётся частично, остальное каша; Gemini узнаёт мелодию «мгновенно», голос «зловещая долина, как Pink Trombone, вязкий, пьяный».
- Улучшать дальше: русские согласные р (три удара), ч, ж, щ, мягкость; другой speaker (есть ли женский?); обводка F0 между слогами.
