## P134. Гармония — план всего трека (`chords.py`)

```python
from autodj.compose import chords as C, lines as L
plan = C.Plan.build("F", trk.tl, home="garage_steps", journey="soul_major", journey_shift=3, seed=seed).attach(trk)
top, _ = L.topline(plan, rng, 65, 77)
keys = plan.voicings("drop2", 50, 78, top=top)        # [(шаг, длина, [ноты])]: голосоведение по всему треку, мелодия сверху
bass = plan.bass(rng, 29, 46, against=keys)            # [(шаг, длина, нота, сила)]: отмечает каждую смену, подходит к следующей тонике
```

- **Аккорд** знает свой лад и для каждой ноты — аккордовая она, краска (9 / 11 / 13) или «избегаемая» (полутон над аккордовым тоном: держать нельзя, пройти можно).
- **Обороты** (`C.IDIOMS`, 12 штук, `C.idioms("deep")`): восьмитактовые фразы с неравным гармоническим ритмом — дорийский вамп с мажорной IV, параллельные m9, линия на нисходящем басу, педаль с движением сверху, цепочки ii–V, фригийская bII, медианты, лидийский мажор.
- **Операторы**: `extend` (краски), `pedal`, `inversions` (бас шагом), `passing` (скользящий аккорд перед сменой), `push` (смена на шестнадцатую раньше), `turnaround`, `tritone`.
- **План по ролям секций**: home — фраза и её изменённый ответ (каждый раз другой поворот); journey — другой оборот (можно в параллельном мажоре); intro / outro — проще и на педали; break — два долгих аккорда; build — доминантовая педаль.
- **Расположения**: `close`, `drop2`, `rootless`, `quartal`, `spread`. Внутри расположения нет полутонов и малых нон; путь выбирается по всей последовательности с наименьшим движением голосов.
- `plan.describe()` — аккордовая сетка по секциям (попадает в сводку рендера), `plan.fingerprint()` — отпечаток для сравнения с прошлыми треками.

## P134. Линии по гармонии (`lines.py`)

```python
ctx  = L.context(plan, keys, bass)                               # что реально звучит на каждой шестнадцатой
h8   = L.hook(plan, rng, 62, 79, bar=8, ctx=ctx)                 # 8 тактов A A' A B из одного мотива
hook = L.tile(h8, plan, 62, 79, [8, 16, 32, 40], ctx, origin=8)  # тот же мотив над другими аккордами — переосмыслен, не транспонирован
ost  = L.ostinato(plan, rng, 74, 88, 24, 56, n=3, step=2, ctx=L.context(plan, keys, bass, hook))   # 6/16 против такта
cnt  = L.counter(plan, hook, rng, 55, 67, ctx)                   # ответы в паузах мелодии
arp  = L.arp(plan, keys, rng, 56, 72, step=1)                    # не начинается заново со сменой аккорда
L.fit(hook, plan, ctx)   # {"avoid": 0.0, "rub": 0.0, "colour": 0.2, ...}
```

Долгие ноты встают на аккордовые тоны или краски и проверяются по реальным интервалам с тем, что звучит; короткие проходят по ладу.
`fit` — мера: `avoid` и `rub` должны быть 0, `colour` 0.15–0.5 (0 = одни аккордовые тоны, плоско). `fix` чинит чужую линию.

## P135. Учёт свежести (`fresh.py`)

Каждый рендер записывает в `shared/fresh_ledger.json`: какие файлы звуков загрузил, рисунки ударных (как сыграно), отпечаток гармонии.
В сводке: `fresh` и `fresh_notes` — «звук X уже в 12 прошлых треках», «рисунок хэтов совпадает с 5 треками», «та же последовательность аккордов уже была в…».

```python
from autodj.compose import fresh
kick = load_sample(fresh.pick(glob.glob(f"{W}/Kicks/*.wav"), rng), .35)     # наименее заезженный из кандидатов
```
```bash
python -m autodj.compose.fresh scan /home/cclaw/claudeclaw-build/workspace/music   # один раз: история старых треков
python -m autodj.compose.fresh top                                                  # самые заезженные звуки
```
Ворота по желанию: `META["gates"] = {"fresh_reuse_max": .3, "fresh_rhythm_max": 1, "fresh_harmony_new": True}`.

## P136. Образец

`docs/examples/deep_harmony_demo.py` — трек, где ничего гармонического не набрано руками. Три стиля (`AUTODJ_DEMO_STYLE=garage|deep|melodic`).
`AUTODJ_DEMO_HARMONY=old` рендерит те же звуки, ритмы и уровни со старой петлёй из четырёх аккордов — для сравнения на слух.

## Порядок работы над новым треком

1. Настроение → `C.idioms(mood)` → выбрать home и journey, которых нет в `fresh_ledger` (`fresh_notes` скажет, если были).
2. `Plan.build(...)` → `voicings`, `bass`, линии из `lines.py`. Сетку аккордов показать Стасу вместе с треком (`summary["harmony"]["chart"]`).
3. Звуки: тональные — из лаборатории (`soundlab`), ударные — через `fresh.pick` по папкам, а не по привычному имени файла.
4. В сводке читать четыре списка: `problems`, `depth_notes`, `fresh_notes`, `line_fit`.
5. Партитуру — в git.
